# Security Policy

## Supported Versions

This is a personal/hobby project without formal version support — the
`main` branch is always the actively maintained version.

## Reporting a Vulnerability

If you find a security issue, please **do not open a public GitHub issue**.
Instead, report it privately by emailing **your-email@example.com** with:

- A description of the issue
- Steps to reproduce it
- Any relevant logs or screenshots

I'll aim to respond within a few days and let you know once it's fixed.
