The reading experience

Verse by verse, in your language

  • Sanskrit, as it was written

    Every verse is shown in Devanagari with a clean transliteration alongside it, so you can read or chant along even if Sanskrit isn't your first script.

  • Kannada, Hindi & English translations

    Translations are added only once they've been sourced and reviewed — so what you read is trustworthy, not machine-guessed. Sanskrit is always available while a chapter's translation is still in progress.

  • Search, bookmarks & progress

    Jump straight to a verse, save the ones that matter to you, and the app remembers exactly where you left off — no sign-in required.

  • Reads well anywhere

    Adjustable text size, a high-contrast mode, and an interface built to feel calm on a small screen as much as a large one.

How it's built

A simple app, honestly put together

The app is built with Expo and TypeScript, so the same codebase runs on Android, iOS and the web. Content is designed the same way throughout — nothing shown to a reader skips review.

App

Expo · React Native · TypeScript

One codebase for the Android app and the web reader, sharing the same screens, content and reading progress logic.

Content

Sanskrit dataset, reviewed translations

All 700 Sanskrit verses ship with the app. Translations move through Draft → Review Required → Human Reviewed → Published before anyone reads them.

Backend

PostgreSQL · Prisma (optional)

An admin panel backed by Postgres manages content review at scale — not required just to read, only for larger content teams.

How do I install an APK without the Play Store?
  1. Download the file above on your Android phone (not a computer).
  2. Open your phone's Settings → Apps → Special access → Install unknown apps, and allow your browser to install apps.
  3. Open the downloaded file and tap Install.
  4. Once installed, you can open it like any other app.

Android will warn you that this app is from an unrecognized developer — that's expected for any app installed outside the Play Store.
